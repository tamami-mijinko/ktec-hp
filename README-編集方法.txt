会社ホームページ：内容とデザインを分離した版

通常、会社情報や文章を変更するときは「site-data.js」だけを変更します。

【site-data.js にまとめてあるもの】
・ページタイトル / Google検索用説明
・会社名 / ロゴ文字
・トップ画像の指定 / キャッチコピー
・「こんな時は」の3項目
・強み
・事業内容
・会社概要
・電話番号
・メールアドレス
・GoogleマップURL
・フッター会社名

【デザイン側】
・index.html：ページの骨組み
・style.css：色、余白、文字サイズ、レイアウト
・app.js：site-data.jsの内容をページに反映する処理
・assets/hero.jpg：現在の仮トップ画像

今後の運用：
友人から変更内容を受け取る → ChatGPTへ内容を渡す → site-data.js中心に更新 → GitHubへ反映 → Cloudflare自動公開

※本番でSearch Console / SEOを仕上げる段階では、会社情報が確定した後に検索向け設定も最終調整します。
